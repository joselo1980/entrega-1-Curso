# Rodó & Asociados - Pre-entrega 1

Estructura base en HTML del sitio web de Rodó & Asociados, estudio jurídico de Montevideo.

## Archivos

- `index.html`: página de inicio.
- `pages/sobre-mi.html`: nosotros.
- `pages/servicios.html`: servicios del estudio.
- `pages/proyectos.html`: preguntas frecuentes.
- `pages/contacto.html`: datos de contacto.
- `assets/img/`: imágenes del sitio.

## Tecnologías

- HTML5 (sin estilos, como pide la consigna).
